🚦 Estados del Sistema

Cómo el sistema clasifica pedidos y ventas internamente

🔵
Pendiente
pedido: pendiente
Pedido recibido pero aún no cobrado. Aparece en la tabla de pedidos activos. El mesero debe liquidarlo.
💚
Liquidado
pedido: entregado
Pedido cobrado y entregado. Tiene una venta ACEPTADA asociada. Se muestra como "Liquidado" en el panel.
❌
Cancelado
pedido: cancelado
Pedido anulado. Nunca se borra — queda en la base de datos para auditoría. NO suma en las ventas del día.
✅
Venta Aceptada
venta: ACEPTADA
Venta válida. Aparece en Caja y suma en todas las estadísticas del día. Tiene su folio único (ej: VENTA-260919-001).
🚫
Venta Anulada
venta: ANULADA
Venta cancelada después de ser cobrada. Permanece en el historial para auditoría pero NO suma en totales ni utilidad.
💳
Crédito → Cartera
cartera: pendiente
Si el método de pago es Crédito, la venta se registra normalmente en Caja Y además se agrega un registro en el módulo de Cartera para cobrar después.

🗑️ Cómo Funciona la Anulación

El sistema maneja 2 escenarios de anulación automáticamente

🛡️ Regla de oro: Nada se borra, todo se anula

Un pedido anulado queda marcado como "cancelado" para siempre en la base de datos. Esto protege la integridad del historial y permite auditorías. La anulación solo cambia el estado — nunca elimina registros.

⚡ Escenario A — Pedido Pendiente

  • El pedido nunca fue cobrado
  • Se hace clic en 🗑️ Anular
  • El pedido pasa a "cancelado"
  • No existía venta → nada que revertir en Caja
  • Desaparece del filtro "Pendientes"

🔴 Escenario B — Pedido ya Liquidado

  • El pedido ya fue cobrado y tiene venta ACEPTADA
  • Se hace clic en 🗑️ Anular (pide confirmación extra)
  • La venta pasa a "ANULADA" en Caja
  • El pedido pasa a "cancelado"
  • Los totales de Caja se actualizan automáticamente

💳 Ventas a Crédito → Módulo Cartera

Cuando se selecciona el método de pago Crédito al liquidar un pedido, el sistema hace dos cosas simultáneamente:

1. Registra la venta normalmente en Caja (aparece como ACEPTADA).
2. Crea automáticamente un registro en el módulo de Cartera con el nombre del cliente, el número de pedido, los productos y el monto pendiente de cobro.

Así puedes hacer seguimiento de todas las deudas de empleados o clientes frecuentes desde el módulo de Cartera.
